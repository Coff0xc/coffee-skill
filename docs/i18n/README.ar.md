# coffee-skill مرجع عربي

## ما هو

`coffee-skill` حزمة مهارات لـ Codex. تغطي هندسة البرمجيات، AI Agent/RAG، واجهات API والبيانات، الواجهات والمستندات، الأمن الدفاعي، الكشف، الاستجابة للحوادث، وإدارة الثغرات.

## لماذا وُجد

- كثرة المهارات الصغيرة تجعل التشغيل التلقائي غير موثوق.
- كثير من العملاء يختارون المهارات أساسا من frontmatter `name` و `description` داخل `SKILL.md`.
- أعمال الأمن تحتاج إلى حدود واضحة للتفويض والاستخدام الدفاعي.
- العمل العملي يحتاج خطوات قابلة للتحقق، وليس نصائح عامة فقط.

## لماذا هو مفيد

- يدمج 87 مهارة مصدر في 15 مهارة شاملة.
- يضيف `coff0xc-skill-router` كمسار احتياطي عند فشل تشغيل مهارة محددة.
- كل مهارة تحتوي على النطاق، الاستثناءات، مصفوفة القدرات، مراحل العمل، مستويات الأدلة، بوابات صارمة، تحقق، وأنماط يجب تجنبها.
- محتوى الأمن يبقى موجها للدفاع المصرح به، الكشف، التقوية، التحقق، والتقارير.

## كيفية الاستخدام

يمكنك الطلب بشكل طبيعي:

```text
Use coff0xc-secure-code-appsec to review this project.
Use coff0xc-detection-response to write detection rules.
Use coff0xc-cloud-devsecops to review Kubernetes and CI/CD risk.
```

إذا لم تعمل المهارة تلقائيا:

```text
Use coff0xc-skill-router to choose the right skill.
```

## أين يستخدم

- مجلدات مهارات Codex المحلية.
- العملاء المتوافقون مع مجلدات `SKILL.md`.
- الهندسة، أنظمة الذكاء الاصطناعي، الوثائق، الأمن الدفاعي، الكشف، وإدارة الثغرات.

## عند فشل التشغيل

1. تأكد أن اسم المجلد يطابق frontmatter `name`.
2. أعد تشغيل Codex أو حدّثه بعد النسخ.
3. أزل أسماء المهارات المكررة.
4. استدع `coff0xc-skill-router` صراحة.

## حدود الأمان

استخدمه فقط مع الأصول أو الكود أو السجلات أو العينات أو المختبرات أو بيئات التدريب التي تملكها أو لديك تفويض صريح لها. لا تستخدمه للوصول غير المصرح، سرقة بيانات الاعتماد، الاستمرارية، التخفي، C2، جمع التصيد، تسريب البيانات، أو الأعمال التخريبية.
