# coffee-skill русская справка

## Что это

`coffee-skill` — это пакет навыков для Codex. Он покрывает разработку ПО, AI Agent/RAG, API и данные, UI и документы, защитную безопасность, детектирование, реагирование на инциденты и управление уязвимостями.

## Зачем он нужен

- Слишком много мелких навыков делает автоматический запуск ненадежным.
- Многие клиенты выбирают навыки в основном по frontmatter `name` и `description` в `SKILL.md`.
- Задачи безопасности требуют четкой авторизации и защитных границ.
- Практическая работа требует проверяемых шагов, а не только общих советов.

## Чем он полезен

- Объединяет 91 исходный навык/workflow в 17 широких навыков и маршрутизатор.
- `coff0xc-skill-router` служит запасным маршрутизатором, если конкретный навык не запустился.
- Каждый навык содержит область применения, исключения, матрицу возможностей, этапы работы, уровни доказательств, жесткие проверки, валидацию и анти-паттерны.
- Материалы по безопасности сфокусированы на разрешенной защите, детектировании, усилении, проверке и отчетности.

## Как использовать

Можно писать естественно:

```text
Use coff0xc-cloud-devsecops to review Kubernetes and CI/CD risk.
Use coff0xc-vulnerability-lifecycle for CVE and patch analysis.
Use coff0xc-detection-response to write detection rules.
```

Если автоматический запуск не сработал:

```text
Use coff0xc-skill-router to choose the right skill.
```

## Где использовать

- Локальные директории навыков Codex.
- Совместимые клиенты, которые загружают папки `SKILL.md`.
- Разработка, AI-системы, документация, защитная безопасность, детектирование и управление уязвимостями.

## Если запуск не сработал

1. Проверьте, что имя папки совпадает с frontmatter `name`.
2. Перезапустите или обновите Codex после копирования.
3. Удалите дублирующиеся имена навыков.
4. Явно вызовите `coff0xc-skill-router`.

## Граница безопасности

Используйте только для собственных или явно разрешенных активов, кода, логов, образцов, лабораторий и учебных сред. Не используйте для несанкционированного доступа, кражи учетных данных, закрепления, обхода защиты, C2, сбора фишинговых данных, эксфильтрации или разрушительных действий.
