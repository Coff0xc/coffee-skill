# Security Policy

## Scope

These skills are intended for authorized engineering, defensive security, detection, hardening, assessment, reporting, and educational lab work.

## Not Supported

Do not use this repository to request or perform unauthorized access, exploitation, credential theft, persistence, detection evasion, C2 operation, phishing collection, data exfiltration, or destructive actions.

## Reporting Issues

If you find unsafe guidance, exposed secrets, or private information in this release candidate, remove it before publication and regenerate the candidate.
